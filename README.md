# 经典返回 / Classic Back

为作用域内的应用恢复经典返回手势（关闭预测性返回）。

Restore classic back gestures for scoped apps (disable predictive back).

## 环境 / Requirements

- Android 13+
- 支持 libxposed API 102 的 LSPosed / LSPosed with libxposed API 102 support

安装后，在 LSPosed 中启用，勾选目标应用的作用域，然后完全结束并重新打开这些应用。

After installation, enable in LSPosed, select the target apps in its scope, then completely close and reopen those apps.
